# Sovereign Local-First Threat Model & Security Architecture

## Overview

Personas_Agentes (PSA) operates under a **Sovereign Local-First Security Architecture**. The platform assumes a zero-trust model regarding external networks while enforcing strict local runtime containment, cryptographic model verification, and automated path veto governance.

---

## Threat Vectors & Mitigation Controls

| Threat Vector | Severity | Mitigation Control | Architecture Component |
|---|---|---|---|
| **Model Weight Tampering / Supply Chain Attack** | Critical | SHA-256 pre-download & post-download cryptographic verification with 1MB highWaterMark streaming | `scripts/download_model.ts` |
| **Unauthenticated Inter-Process Interception** | High | Mutual TLS (mTLS) with TLS 1.3 protocol requirement and client certificate validation | `src_native/hub/main.go` |
| **Unsafe Command / File System Destruction** | Critical | Veto Engine path protection blocking `.git`, `node_modules`, system paths, binary artifacts | `src_local/core/governance/veto_engine.ts` |
| **Micro-Agent Execution Memory Escalation** | Medium | Ephemeral WASI WebAssembly sandboxing with Sovereign Resource Budget & Instant Purge | `src_native/wasm_agents/` |
| **Malicious Code Patch Injection** | Critical | Idris 2 Dependent-Type Formal Verification checking loop termination, bounds, and SQL safety | `src_local/engines/healing/formal_verification_engine.ts` |
| **SQL Injection in Log Storage** | High | Parameterized SQLite queries across all storage plugins (CWE-89 mitigation) | `src_local/psa/plugins/core/sqlite_plugin.ts` |

---

## Security Invariants (Inviolable Guarantees)

### 1. Cryptographic Model Weight Integrity
All local `.gguf` model weights downloaded or loaded by `scripts/download_model.ts` must match hardcoded SHA-256 digests. If a digest mismatch is detected:
1. The corrupted model file is immediately deleted from disk.
2. An error is raised preventing model loading or inference execution.
3. The model downloader automatically attempts a clean re-download from verified origins.

### 2. Network Isolation & Sovereign Local Fallback
PSA operates completely offline without sending source code or telemetry to remote servers unless explicitly configured for Hugging Face Serverless API failover. If network connectivity fails or remote providers return errors, `LocalSLMEngine` automatically downgrades to deterministic local static response fallbacks.

### 3. Veto Engine Governance Path Rules
`VetoEngine` enforces static governance rules preventing agents from modifying critical infrastructure or protected system files:
- **Blocked Directories:** `.git/`, `node_modules/`, `build/`, `dist/`, `target/`
- **Blocked File Extensions:** `.dll`, `.exe`, `.pyc`, `.o`, `.so`, `.dylib`, `.key`, `.pem`
- **Blocked Security Paths:** `.env`, `system_vault.db`, `tls_certs/`

### 4. WASI WebAssembly Sandbox Isolation
Zig WASM micro-agents (`agent_audit.wasm`, `agent_security.wasm`, `agent_git.wasm`, `agent_telemetry.wasm`, `agent_database.wasm`, `agent_linter.wasm`) execute within isolated WebAssembly environments:
- Zero direct access to host file system or network sockets.
- Isolated linear memory memory buffers (`WebAssembly.Memory`).
- Instant Purge upon function completion.

### 5. Idris 2 Dependent-Type Formal Safety Proofs
Patches generated by auto-healing or refactoring engines are mathematically evaluated against 4 dependent-type safety contracts before application:
- **Finite Loop Termination Proof**
- **Memory & Array Index Bounds Proof**
- **SQLite Invariant Preservation Proof**
- **Type Safety & Non-Null Pointer Guard Proof**
